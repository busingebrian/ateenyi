1) Who This Experience Serves

External Users
[ Taxpayers ] [ Tax Agents ] [ Tax Auditors ]
Goal: Fast, secure access to own services and profile information
Need: Clear login, password recovery, and predictable access outcomes
Internal Users
[ Commissioner General ] [ Commissioners ] [ Assistant Commissioners ]
[ Managers ] [ Supervisors ] [ Officers ] [ STEs ]
Goal: Controlled operations based on role, group, and station hierarchy

2) Experience Flow (Executive Journey)

Identify

User profile exists or is created (registration or HR/ERP feed)
Unique user identity is validated

Authenticate

Username + Password + OTP
Auto lock after failed attempts and inactivity controls

Authorize & Enforce

Role/group/station policies decide access
System allows, denies, or blocks protected actions
Every critical event is logged: login, logout, access attempts, modifications, permission changes
Every action is traceable to a user account for accountability and audit review
