eTAX2 User Management & Access Control Wireframe

Based on URS and aligned to TOGAF principles (business alignment, security, interoperability) and IA principles (clear hierarchy, consistency, traceability)

Requirement Name: User Management
Business Owner: BPR
Version: 1.0
Scope: eTAX2
Executive Wireframe User Management Wireframe Access Control Wireframe Login Wireframe

1) End-to-End Access Control Process

External User Journey (Taxpayer / Agent / Auditor)
Step 1: Identification → user category + first-time registration or migrated account
Step 2: Authentication → username + password + OTP (SMS / Email / Authenticator / WhatsApp)
Step 3: Authorization → role check and policy evaluation (default deny)
Step 4: Access Enforcement → allow/deny action, session validation, auto lock controls
Step 5: Auditing → login/access/activity logs with timestamp and result
Internal User Journey (URA Staff)
Step 1: Identification → HR/ERP feed creates user profile + user category
Step 2: Authentication → username + password + OTP + account active check
Step 3: Authorization → role/group/station hierarchy for approvals
Step 4: Access Enforcement → PEP interception + decision enforcement + session kill on new machine
Step 5: Auditing → trace all actions to specific user account

2) Core Security Controls Dashboard

Identification Controls

[ Unique username check ]
[ Active user validation ]
[ Internal user source: HR/ERP sync ]

Authentication Controls

[ Username + password gate ]
[ OTP challenge (multi-channel) ]
[ Failed attempts lock (temporary + account lock) ]

Authorization Controls

[ Role + permissions resolver ]
[ Group + station mapping ]
[ Least privilege + default deny ]

Enforcement Controls

[ PEP check before protected action ]
[ Block restricted pages/actions ]
[ Inactivity timeout + session replacement ]
